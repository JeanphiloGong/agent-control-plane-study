# Herdr Server / Client v3：多客户端与背压隔离

[模块路线图](../plan.md) · [上一版 v2](../v2/plan.md) · [本版正文](multi-client-backpressure.md) · [下一版 v4](../v4/plan.md)

## 版本定位

接续 v2 的运行时、事件和本地 API。让多个 thin client 同时读取 pane 更新。运行时为每条连接分配容量为 2 的队列，满载时移除该连接并记下过载事件。队列装的是 pane 更新，Herdr 的渲染帧合并属于上游实现。

## 实现顺序

1. 将运行时客户端集合改成发送端注册表。创建 pane 时非阻塞发布，过载连接从注册表移除。
2. 握手时一起注册队列和读取当前 pane ID。会话消费自己的 receiver，主动离开或意外释放只清理对应连接。

## 验收与交接

用三个连续 pane 更新填满一个停读客户端的队列。健康客户端收到全部更新，停读客户端看到 Closed，重连者看到原有 pane，另一个客户端主动 Detach 也不会中断发布。cargo test 同时执行 v1 的原有用例。v4 使用这套连接注册表做接管和重连。
